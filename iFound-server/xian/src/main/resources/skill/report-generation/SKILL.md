### 字段说明

- 需关注：`是`表示该区域存在告警/故障/环境异常，`否`表示正常
- 能耗状态：接口返回的状态描述，缺失时按状态码转换为`正常`/`异常`
- 设备状态：`故障`/`告警`/`正常`
- 事件等级：`告警`(3)、`故障`(4)、`火警`(10)
- 时间：已统一为 `yyyy-MM-dd HH:mm:ss`
- 当日客流：`entryCount` 当日累计发送人数、`exitCount` 当日累计到站人数，保持不变

### echarts 图表规范

图表使用 ` ```echarts ` 代码块包裹合法的 JSON 配置。所有属性名必须用双引号，颜色统一使用以下调色板：

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | `#409EFF` | 柱状图、进度环主色 |
| 成功 | `#67c23a` | 正常/在线/达标 |
| 警告 | `#e6a23c` | 需关注/偏低 |
| 危险 | `#f56c6c` | 异常/告警/故障 |
| 灰色 | `#909399` | 背景/未启用/无数据 |
| 底色 | `#e5e5e5` | 环形底色 |

### 总结要求

每个图表/表格下方必须附带文字总结，采用以下标注体系：

| 标注 | 含义 | 示例 |
|------|------|------|
| ✅ | 正常/达标 | ✅ 高架候车层：温度 20.5~22.5°C，CO₂ 395~494ppm（优秀） |
| ⚠️ | 需关注/有风险 | ⚠️ 出站层：湿度偏高 80~95%，可能结露风险 |
| ❌ | 异常/故障 | ❌ TX31_1传感器温度50.7°C异常，需更换 |

引用标准时需附参考值，例如：
- 温度 22~26°C、湿度 40~60%、CO₂ < 1000ppm
- 健康率 ≥ 95% 为优秀，85%~95% 为一般，< 85% 需整改

### 第五部分：问题诊断与改进建议

逐条列出发现的问题，每条包含：
- 问题描述（`⚠️` 或 `❌` 标注）
- 根因分析
- 改进建议

示例：
```
⚠️ 能耗数据异常提示
6月总能耗仅 21.0 kWh，非零天数仅 6 天。年维度总能耗 22.0 kWh。数据采集不完整。
建议排查计量设备连接状态和数据采集链路。
```

### 第六部分：运营总结

用 2~3 句话概括整体运营状况，覆盖健康率、客流、能耗三个方面。
